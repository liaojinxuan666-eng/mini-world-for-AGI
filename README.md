# mini-world-for-AGI

最小认知架构，阶段 3：世界模型。在潜空间预测下一状态。

## 目标

给混合序列引擎加一个"内部模拟器"，让智能体能在行动前想象后果。为阶段 5（内在动机）提供基础：预测误差 = 惊讶 = 好奇心信号。

## 任务：GridWorld 隐式动力学

100×100 网格，每格随机赋予一个固定类型：

- **正常 (90%)**：动作直接生效，上 → y+1
- **镜像 (7%)**：动作反向，上 → y-1
- **传送 (3%)**：走到即跳到固定位置

模型看不到格子类型，只能从历史观测推断。

**输入序列**：
 
[x_1, y_1, a_1, x_2, y_2, a_2, ..., x_t, y_t, a_t]

**目标**：预测 `(x_{t+1}, y_{t+1})`。

词表：0-99 x 坐标，100-199 y 坐标，200-203 动作，共 204。

## 架构

复用阶段 1 的 Hybrid 主干（3 SSM → 1 Attn → 3 SSM），把词表扩到 204，直接做 next-token 预测。1.45M 参数。

**训练**：教师强制，loss 在 `(x_{t+1}, y_{t+1})` 两个位置计算。

**评估**：自回归 rollout，从 8 步真实前缀出发，模型用自己预测的位置当下一步输入，连续预测 50 步。

## 结果

**训练**：3000 步，T4 GPU，seed=42，单世界。

**单步预测**：

| 世界 | acc |
|---|---:|
| 训练世界 | 0.9840 |
| 全新世界 | 0.9187 |

**Rollout（自回归）**：

| 步数 | 训练世界 | 全新世界 |
|---|---:|---:|
| 1 | 0.9688 | 0.8438 |
| 5 | 0.8594 | 0.5312 |
| 10 | 0.7969 | 0.3750 |
| 20 | 0.5781 | 0.0938 |
| 30 | 0.5312 | 0.0625 |
| 50 | 0.2031 | 0.0000 |

## 结论

**已达成**：
- 模型确实在做推断，不是照抄（单步 0.98 ≠ 1.0）
- 对未见过的世界有一定泛化（0.92）
- 短程 rollout（≤10 步）可用

**未达成**：
- 长程 rollout（>20 步）误差累积，发散
- 泛化到新世界后 rollout 更早崩溃

**这是世界模型原型的典型表现。** Dreamer、IRIS 等系统也都在几十步后发散。当前阶段目标（"能在潜空间预测下一状态"）已达成。

**下一步优化方向**（留给后续阶段）：
- 每 batch 换新世界，强迫学习规则而非地图
- 用内在动机（预测误差）做课程学习
- 加 RAG 检索长程上下文

## 踩坑

- **训练目标错位**：`logits[i]` 对 `target[i]` 会让模型照抄输入，单步 acc 虚高到 1.0。必须 `logits[:, :-1]` 对 `target[:, 1:]`
- **rollout 才是真判据**：单步 acc=1.0 不代表世界模型成立
